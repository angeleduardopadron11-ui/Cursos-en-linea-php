#  Plataforma de Cursos Online (PHP & MVC)

Sistema integral para la gestión de cursos, alumnos y profesores, desarrollado como proyecto académico de 4to semestre bajo estándares de ingeniería de software.

##  Características Principales
- **Arquitectura MVC:** Separación clara entre lógica de negocio, interfaz y datos.
- **Seguridad en Datos:** Implementación de MariaDB/MySQL para persistencia robusta.
- **Gestión de Dependencias:** Uso de **Composer** para la integración de librerías externas.
- **Paradigma POO:** Código estructurado mediante Programación Orientada a Objetos.

##  Stack Tecnológico
- **Lenguaje:** PHP 8.x
- **Base de Datos:** MariaDB / MySQL
- **Gestor:** Composer
- **Frontend:** HTML5, CSS3, JavaScript

## Instalación
1. Clonar el repositorio.
2. Ejecutar `composer install` para instalar dependencias.
3. Importar el archivo `.sql` incluido en la carpeta correspondiente.
